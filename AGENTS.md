# Calendar Sidebar

Always-on-top Windows desktop sidebar showing today's Google Calendar events. PyQt6 hosts a WebEngine that renders a Svelte/SvelteKit frontend; a FastAPI/uvicorn backend runs on a background thread and handles Google OAuth2 + event CRUD. A system tray icon provides show/hide and quit.

## Architecture

```
widget.py    PyQt6 window, tray icon + server thread launcher
server.py    FastAPI backend: OAuth2 flow, /api/events CRUD, SPA static serving
src/         Svelte/SvelteKit frontend (adapter-static)
build/       Compiled frontend — generated by bun run build (gitignored)
run.vbs      Silent Windows launcher (hides the console)
log/         Runtime log files: widget.log, server.log (gitignored) — the only output when run via VBS
.env         Google OAuth credentials (gitignored)
.tokens.json Persisted OAuth tokens (gitignored)
```

## Running

```
bun install          # install frontend deps (once)
bun run build        # compile Svelte frontend (required once)
uv run widget.py     # start the app (uv handles all Python deps)
```

Or double-click `run.vbs` for a silent, no-console launch. All log output goes to `log/`.

## Ports

The API server binds 8764 by default and scans upward for a free port if it's taken. The OAuth redirect URI (`GOOGLE_REDIRECT_URI`, default `http://localhost:8764/api/auth/callback`) must match the registered port in Google Cloud Console — if the server falls back to another port, first-time login needs `GOOGLE_REDIRECT_URI` set accordingly. Once `.tokens.json` exists, the port doesn't matter.

## Python deps

Declared in `pyproject.toml`; `uv run` installs them automatically into the project environment. No inline `# /// script` headers, no pip.

## Frontend deps

Bun only — `bun.lock` is the lockfile. Do not add `package-lock.json` or `pnpm-workspace.yaml`.

## Google OAuth setup

1. Create an OAuth 2.0 credential in Google Cloud Console (type: web application).
2. Add `http://localhost:8764/api/auth/callback` as an authorised redirect URI.
3. Copy `.env.example` to `.env` and fill in `GOOGLE_CLIENT_ID` and `GOOGLE_CLIENT_SECRET`.
4. Open the app and navigate to `/api/auth/google` to complete the first-time auth flow.

## Debugging

Check `log/widget.log` and `log/server.log` first. Key log lines to look for:

| Log message | What it means |
|---|---|
| `Missing Google OAuth config` | `.env` is missing or incomplete |
| `Token file not found` | Not yet authenticated — visit `/api/auth/google` |
| `API request rejected — user not authenticated` | 401 on event fetch; same fix |
| `Credential refresh failed` | Refresh token revoked; re-authenticate |
| `API server not ready yet — retrying` | Widget waits for the port to bind before loading the UI |
| `Server will run on port ... but GOOGLE_REDIRECT_URI points at ...` | Port fallback broke first-time login; see Ports |

## Conventions

- Python: `uv` only (no pip), f-strings, full type hints, loguru for all logging.
- No `import *`.
- Keep `widget.py` focused on the Qt layer; keep business logic in `server.py`.
- Shutdown path: Qt quit → `CalendarWindow.shutdown()` sets uvicorn's `should_exit` for a graceful stop.
